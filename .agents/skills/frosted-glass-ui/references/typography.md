# Frosted Glass Typography

Use the typography defined in `src/app/styles/frosted-glass.css`.

- **Font Family**: `var(--font-sans)` (`Inter`)
- **Font Sizes**:
  - `var(--font-size-hero)`
  - `var(--font-size-section)`
  - `var(--font-size-body)`
  - `var(--font-size-caption)`

Ensure readability. Contrast is handled automatically by using `var(--on-surface)` and `var(--on-surface-variant)` text colors.
