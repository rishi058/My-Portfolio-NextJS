# Neo-Brutalism Colors

Colors are strictly defined in `src/app/styles/neo-brutalism.css`. Do not invent hex codes.

- **Background**: `var(--background)` (`#FFFDF5` / `#1A1A1A`)
- **Primary**: `var(--primary-400)` (`#FFDE00` - Electric Yellow)
- **Secondary**: `var(--secondary-500)` (`#00BFFF` - Electric Blue)
- **Borders & Shadows**: `var(--outline)` (`#0D0D0D` / `#FFFDF5`)
- **Text**: `var(--on-surface)` and `var(--on-surface-variant)`

Never use gradients. Neo-Brutalism uses flat, solid fills.
