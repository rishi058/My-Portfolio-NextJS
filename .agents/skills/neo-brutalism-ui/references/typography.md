# Neo-Brutalism Typography

Use the typography defined in `src/app/styles/neo-brutalism.css`.

- **Font Family**: `var(--font-sans)` (`Space Grotesk`)
- **Font Sizes**:
  - `var(--font-size-hero)`
  - `var(--font-size-section)`
  - `var(--font-size-body)`

Headings should use `font-weight: 900`. Buttons should use `text-transform: uppercase` and `font-weight: 700`.
