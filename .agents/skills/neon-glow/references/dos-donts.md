# Neon Glow Do's and Don'ts

## Do
- **DO** use `transform: scale(var(--card-hover-scale))` (1.02) to create smooth, subtle lift on hover.
- **DO** rely on `var(--card-hover-glow)` for interactive feedback.
- **DO** use `Geist` for standard UI text and `JetBrains Mono` for technical labels and buttons.

## Don't
- **DON'T** use hard-offset shadows (that is Neo-Brutalism).
- **DON'T** use blur filters to build glass (that is Frosted Glass).
- **DON'T** use intense red/cyan glitch colors (that is Cyberpunk). Keep the palette strict to Teal and Sky Blue.
