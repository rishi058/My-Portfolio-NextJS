# Neon Glow Typography

Use the typography scale defined in `src/app/styles/neon.css`.

- **Sans Font**: `var(--font-sans)` (`Geist`). Used for headers, descriptions, and body text.
- **Mono Font**: `var(--font-mono)` (`JetBrains Mono`). Used for tags, chips, buttons, and code blocks.

## Scale
- `var(--font-size-hero)`: 38px (54px md)
- `var(--font-size-section)`: 32px
- `var(--font-size-body)`: 16px
- `var(--font-size-caption)`: 12px

Headings generally use tight letter spacing (`var(--letter-spacing-tight)`), while buttons and mono elements use wide spacing (`var(--letter-spacing-wide)`).
